# Multi-Agent Compatibility

Zepher integrates via \`AGENTS.md\` which serves as the execution contract for any compatible agent (Claude, Antigravity, Gemini).

The project context stays in \`.zepher/\`, independent of the agent framework.

If you have specific agent instructions, you can still use \`CLAUDE.md\` or \`GEMINI.md\`, but \`AGENTS.md\` serves as the universal anchor.
